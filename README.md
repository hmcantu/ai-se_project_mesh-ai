# MeshAI

A full-stack AI assistant app. Users can upload documents to a knowledge base and query them through a chat interface. Utilizes RAG via MongoDB and OpenAI.

**Live:** <https://haileyengapp.twilightparadox.com/>

## Tech stack

- React
- TypeScript
- Express
- MongoDB
- Docker
- Caddy
- AWS EC2
- GitHub Actions

## Getting started

Prerequisites: Node.js 20+, Docker

1. Clone the repository:
   ```bash
   git clone https://github.com/hmcantu/ai-se_project_mesh-ai.git
   ```
